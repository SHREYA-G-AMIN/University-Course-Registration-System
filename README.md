## 🎯 Demonstrates real-world application of OOP concepts

### 📌 Project Overview

The University Course Registration System streamlines academic processes by separating user roles and managing dynamic course data efficiently.

**Key Highlights:**

**Abstract Base Architecture**
- Uses an abstract User class for a scalable hierarchy

**Dynamic Enrollment System**
- Manages student courses using LinkedList and ArrayList

**Role-Based Access Control**
- Separate modules for Students and Admins with authentication

---

### ✨ Features

**👩‍🎓 Student Module**
- Course Discovery
View Undergraduate and Graduate course catalogs
- Smart Enrollment
Enroll using course codes (e.g., CS101, CS201)
- Schedule Tracker
Real-time weekly schedule updates (e.g., Monday to Friday)
- Course Modification
Drop enrolled courses by code with immediate updates

**🧑‍💼 Admin Module**
- System Oversight
Add new courses for specific student categories
- Time Management
Set or update course schedules
- Registry Cleaning
Remove courses from the system by course code

---

### ⚙️ Core Architecture (OOP Implementation)

The system is built on four main pillars:
- Course
- Manages course identity and scheduling (Code, Name, Schedule)
- User (Abstract Class)
- Defines shared protected attributes like name and id
- Student & Admin
- Specialized subclasses implementing business logic
- CourseRegistrationSystem
- Central engine managing users, course lists, and interactions
